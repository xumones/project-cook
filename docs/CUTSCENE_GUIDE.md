# คู่มือทำ cutscene ทีละขั้น

คู่มือนี้เขียนสำหรับคนที่เพิ่งเริ่มใช้ Timeline ถ้าอยากดูของจริงประกอบ ให้เปิดฉาก `TestArea` แล้วดู `Cutscenes/Stage_TestArrival` ซึ่งทำตามขั้นตอนด้านล่างทุกข้อ โครงสร้างของระบบอยู่ที่ `docs/ARCHITECTURE.md` หัวข้อ Cutscene

## ศัพท์ที่ต้องรู้

| คำ | ความหมาย |
|---|---|
| Timeline | หน้าต่างเรียงเหตุการณ์ตามเวลา หน้าตาเหมือนโปรแกรมตัดต่อวิดีโอ |
| Track (แถว) | แถวหนึ่งแถวใน Timeline เช่น แถวกล้อง แถวท่าทาง |
| Clip | ก้อนเหตุการณ์บนแถว เช่น "ใช้กล้องมุมกว้าง วินาทีที่ 0–3.5" |
| PlayableDirector | component ที่เล่น Timeline หนึ่งอัน |
| Cinemachine Camera | กล้องเสมือน เก็บแค่ตำแหน่งและมุม ไม่ได้วาดภาพเอง มีกี่ตัวก็ได้ |
| Priority | เลขลำดับของกล้องเสมือน ตัวที่สูงสุดคือภาพที่ผู้เล่นเห็น |

## cutscene แบบวิดีโอหรือภาพนิ่ง (ทำง่ายกว่า ไม่ต้องใช้ Timeline)

ในไฟล์ข้อมูล ตั้ง **Content** เป็น
- **Video**: ลากไฟล์วิดีโอ (mp4 / webm) ใส่ช่อง Video เล่นจนจบแล้วปิดเอง
- **Slides**: เพิ่มหน้าในรายการ Slides แต่ละหน้ามี Image (ภาพเต็มจอ ว่าง = พื้นดำ), Speaker (ผู้พูด ว่างได้), Text (ข้อความในหน้าต่างคุย ว่าง = แสดงแต่ภาพ) ผู้เล่นกด F หรือคลิกซ้ายเพื่อไปหน้าถัดไป

แบบนี้ไม่ต้องทำขั้นที่ 2–5 (ไม่ต้องมี Stage ในฉาก) เล่นได้ทุกที่ เข้าออกด้วยจอดำ หยุดเวลาและเสียงเกมเสมอ ช่อง Kind, Transition และ Allow Look จึงไม่มีผล ยังต้องใส่ไฟล์ในรายการ Cutscenes และตั้งตัวกระตุ้นเหมือนเดิม ดูตัวอย่างที่ `GameData/Cutscenes/Cutscene_TestSlides` (เดินเข้าเสา `Event_Marker` ใน TestArea)

## cutscene แบบ Timeline มี 3 ชิ้น

1. **`CutsceneSO`** ไฟล์ข้อมูลใน `GameData/Cutscenes/` บอกว่าเล่นเมื่อไหร่และเล่นแบบไหน
2. **`CutsceneStage`** วางในฉากตรงจุดที่ cutscene เกิด ถือ Timeline กล้อง และนักแสดง
3. **ตัวกระตุ้น** มี 4 แบบ: เดินเข้ากล่อง `WorldEventTrigger`, รับเควส, เควสจบ, หรือปิดบทสนทนากับ NPC คนหนึ่ง

## ขั้นที่ 1 · สร้างไฟล์ข้อมูล

1. ที่ `GameData/Cutscenes/` คลิกขวา → Create → ProjectCook → Cinematics → Cutscene ตั้งชื่อ `Cutscene_<ชื่อ>`
2. กรอกช่องต่อไปนี้

| ช่อง | ใส่อะไร |
|---|---|
| Cutscene Id | รหัสไม่ซ้ำ เช่น `chef_first_meet` **ห้ามเปลี่ยนหลังมี save** |
| Trigger | ชนิดของสิ่งที่ทำให้เล่น (ดูตารางด้านล่าง) |
| Trigger Id | รหัสที่ต้องตรงกัน ความหมายขึ้นกับ Trigger |
| Required Quests | ต้องจบเควสเหล่านี้ก่อน ตัวกระตุ้นถึงจะนับ ว่างได้ |
| Play Once | ติ๊ก = เล่นครั้งเดียวทั้งเกม (cutscene เนื้อเรื่อง) ไม่ติ๊ก = เล่นทุกครั้งที่เดินเข้า |
| Kind | Realtime = โลกเดินต่อ, Full = หยุดเวลาทั้งเกมระหว่างเล่น |
| Transition In / Out | Blend = เลื่อนกล้องจากหรือกลับสายตาผู้เล่น, Fade = จอดำ, Cut = ตัดทันที |
| Allow Look | ติ๊ก = ตอนเป็นมุมสายตาผู้เล่น หันกล้องได้ในกรอบเล็กๆ |
| Finish Event | รหัสเหตุการณ์ที่ส่งตอนจบ ใช้เริ่มเควส (Start Event) หรือ cutscene ถัดไป ว่างได้ |

**Trigger แต่ละแบบ**

| Trigger | Trigger Id คือ | ตัวอย่าง |
|---|---|---|
| WorldEvent | Event Id ของ `WorldEventTrigger` หรือ Finish Event ของ cutscene อื่น | เดินถึงหลังบ้าน |
| QuestStarted | Quest Id ของ `QuestSO` | รับเควสจากเชฟแล้วเชฟพาไปดูห้อง |
| QuestCompleted | Quest Id ของ `QuestSO` | ส่งเควสแล้วมีฉากขอบคุณ |
| DialogueEnded | Npc Id ของ `NPCProfileSO` | คุยกับเชฟจบแล้วมีคนเคาะประตู |

ถ้าตัวกระตุ้นเกิดตอนผู้เล่นยังคุยอยู่ (เช่นรับเควสในบทสนทนา) cutscene จะรอจนปิดหน้าต่างคุยแล้วค่อยเล่นทันที ไม่ต้องตั้งอะไรเพิ่ม

3. เปิดฉาก `Core` → `Systems` → `CutsceneScheduler` แล้วลากไฟล์นี้ใส่รายการ **Cutscenes** ถ้าลืมขั้นนี้ cutscene จะไม่มีวันเล่น

## ขั้นที่ 2 · วางจุดตั้งฉากในฉาก

1. ในฉากพื้นที่ สร้าง GameObject ว่าง ตั้งชื่อ `Stage_<ชื่อ>` (แนะนำให้รวมไว้ใต้ GameObject ชื่อ `Cutscenes`)
2. Add Component → `CutsceneStage` แล้ว Unity จะใส่ PlayableDirector ให้เอง
3. ลากไฟล์ `Cutscene_<ชื่อ>` ใส่ช่อง **Cutscene**
4. ถ้าอยากย้ายผู้เล่นตอนจบ ให้สร้าง GameObject ว่างตรงจุดปลายทางแล้วลากใส่ **Player End Point** ตอนออกจะเป็นจอดำเองเพื่อไม่ให้เห็นการวาร์ป

## ขั้นที่ 3 · สร้าง Timeline

1. เปิดหน้าต่าง Window → Sequencing → Timeline
2. เลือก `Stage_<ชื่อ>` ใน Hierarchy แล้วกดปุ่ม **Create** ในหน้าต่าง Timeline บันทึกไฟล์ไว้ที่ `GameData/Cutscenes/<ชื่อ>.playable`
3. ไม่ต้องตั้ง Play On Awake หรือ Wrap Mode ระบบตั้งให้เองตอนเล่น

## ขั้นที่ 4 · กล้อง

1. สร้างกล้องเป็นลูกของ Stage: GameObject → Cinemachine → Cinemachine Camera
2. จัดมุมโดยหมุนมุมมองของหน้าต่าง Scene ให้ได้ภาพที่ต้องการ เลือกกล้องแล้วกด GameObject → Align With View (Ctrl+Shift+F)
3. **ปล่อย Priority ไว้ที่ 0** ถ้าตั้งสูงกว่ากล้องผู้เล่น (1) กล้องนี้จะแย่งภาพตลอดเวลา
4. ในหน้าต่าง Timeline กด **+** → Cinemachine Track **ไม่ต้องลากอะไรใส่ช่องผูกของแถว** ระบบผูกกับกล้องหลักให้ตอนเล่น
5. คลิกขวาที่แถว → Add Cinemachine Shot Clip แล้วลากกล้องใส่ช่อง Cinemachine Camera ของ clip
6. กติกาของแถวกล้อง
   - clip วางติดกัน = ตัดภาพ ซึ่งเป็นธรรมเนียมเวลาเปลี่ยนมุมกลางฉาก
   - clip วางซ้อนกัน = เลื่อนกล้องนุ่มๆ ช่วงที่ซ้อนกันคือเวลาเลื่อน
   - ช่วงที่ไม่มี clip = ภาพจากสายตาผู้เล่น
   - **อย่าใส่ Ease In ที่ clip แรก หรือ Ease Out ที่ clip สุดท้าย** ภาพตอนเข้าและออกถูกตั้งที่ Transition In / Out ของไฟล์ข้อมูลแล้ว

## ขั้นที่ 5 · นักแสดง

1. NPC หรือของที่จะขยับต้องเป็นลูกของ Stage และมี component **Animator**
2. ใน Timeline กด **+** → Animation Track แล้วลากตัวนักแสดงใส่ช่องผูกของแถว
3. วิธีอัดท่าแบบง่าย: กดปุ่มวงกลมสีแดงที่แถว เลื่อนหัวอ่านไปเวลาที่ต้องการ ขยับตัวนักแสดงในหน้าต่าง Scene แล้ว Unity จะจดตำแหน่งเป็น keyframe ให้ เสร็จแล้วกดปุ่มแดงอีกครั้ง
4. ถ้ามีไฟล์ท่าทาง (.anim หรือท่าจาก FBX) อยู่แล้ว ลากไฟล์นั้นใส่แถวได้เลย
5. **ถ้าท่านั้นจดตำแหน่งในฉากไว้แล้ว (เช่น "เดินจากจุด A ไปจุด B")** ให้คลิก clip แล้ว **เอาติ๊ก Remove Start Offset ออก** ค่าเริ่มต้นของช่องนี้คือติ๊กไว้ ซึ่งทำให้ Unity ตัดตำแหน่งเริ่มของท่าทิ้ง แล้วไปเริ่มเดินที่ตำแหน่งของแถว (0, 0, 0) แทน ผลคือนักแสดงไปโผล่ผิดที่และจมพื้น ส่วนท่าที่ขยับอยู่กับที่ เช่น โบกมือ ปล่อยติ๊กไว้ได้

## ขั้นที่ 5.5 · บทพูด

1. ใน Timeline กด **+** → Dialogue Line Track ไม่ต้องผูกอะไร
2. คลิกขวาที่แถว → Add Dialogue Line Clip แล้วตั้งค่า
   - **Speaker**: ลากไฟล์ `NPC_...` ของผู้พูด ว่าง = ไม่แสดงชื่อและรูป
   - **Line**: เลือกประโยคจาก String Table (ระบบแปลภาษา)
   - **Wait For Advance**: ติ๊ก = ถ้าผู้เล่นยังไม่กด F หรือคลิกซ้ายตอน clip จบ ภาพทั้งหมดจะค้างรอ ไม่ติ๊ก = บรรทัดหายเองตอน clip จบ เหมาะกับประโยคสั้นที่ไม่สำคัญ
3. ความยาวของ clip คือเวลาที่ภาพเดินไประหว่างผู้เล่นอ่าน ถ้าผู้เล่นอ่านช้ากว่านั้น ภาพจะค้างรอที่ท้าย clip
4. clip วางต่อกันพอดีได้เลย บรรทัดถัดไปจะรอจนบรรทัดก่อนถูกอ่านจบ
5. **ระหว่างค้างรอ นักแสดงที่ผูกกับแถวท่าทางของ Timeline จะนิ่งเป็นรูปปั้น** (ทดลองกับ NPC#1 แล้ว 2026-10-11) และการเว้นช่องว่างในแถวท่าทางก็ไม่ช่วย ช่วงว่างจะได้ท่านิ่งๆ ท่าหนึ่งแทน ส่วนนักแสดงที่ **ไม่ได้** ผูกกับ Timeline ยังเล่นท่า idle ของ Animator Controller ต่อตามปกติ วิธีทำให้ NPC ยังมีชีวิตตอนรอบทพูด:
   - ถ้า NPC แค่ยืนคุย ไม่ต้องผูก NPC กับ Timeline เลย ปล่อย Animator Controller เล่น idle เอง
   - ถ้า NPC ต้องเดินด้วย ให้ทำ GameObject แม่ (เช่น `Mover`) ครอบโมเดลไว้ ผูกแถวท่าทางกับ Animator ของแม่ แล้วอัดแค่ตำแหน่งของแม่ ส่วน Animator ของโมเดลข้างในปล่อยให้ Controller เล่นท่าเอง ตอนค้างรอ ตัวจะหยุดที่เดิมแต่ท่า idle ยังขยับ

## ขั้นที่ 6 · ตัวกระตุ้น

ถ้า Trigger เป็น WorldEvent ให้วาง GameObject ที่มี `BoxCollider` (ติ๊ก Is Trigger) + `WorldEventTrigger` ตรงจุดที่อยากให้ cutscene เริ่ม แล้วใส่ **Event Id** ให้ตรงกับ Trigger Id ของไฟล์ข้อมูล แบบอื่นไม่ต้องวางอะไรในฉาก ในฉาก TestArea ใช้วิธีก๊อปเสา `WorldEvents/Event_Marker` มาแก้รหัส

## ขั้นที่ 7 · ทดสอบ

- กด Play จากฉากนั้นได้เลย แล้วเดินเข้าจุดตัวกระตุ้น
- ระหว่างเล่น กด **F หรือคลิกซ้าย** เพื่อไปต่อบทพูด (กดครั้งแรกตอนกำลังพิมพ์ = แสดงทั้งบรรทัด) และกด **Enter ค้าง 1 วินาที** เพื่อข้าม ผลตอนจบจะเหมือนดูจนจบ
- ตอนพัฒนา save ปิดอยู่ กด Play ใหม่ทุกครั้งจึงเริ่มใหม่หมด cutscene แบบเล่นครั้งเดียวจะเล่นอีกครั้งในรอบใหม่
- ถ้ากำลังทดสอบเรื่องอื่นแล้วไม่อยากดู cutscene ให้ติ๊ก **Skip Cutscenes** ที่ `GameData/Dev/DevSettings`

## กล้องสลับมุมระหว่างคุยกับ NPC (ไม่ใช่ cutscene)

บทสนทนาปกติตัดมุมกล้องเองได้ ไม่ต้องใช้ Timeline ทำแบบนี้กับ NPC ที่อยากให้มีมุมกล้อง (ตัวอย่าง: NPC#1 ในฉาก Home)
1. ใส่ `NPCFacing` ที่ตัว NPC เพื่อให้หันมาหาผู้เล่นตอนเริ่มคุย และหันกลับเมื่อผู้เล่นกลับไปเดินสำรวจ (เช่น เปิดร้านต่อจากบทสนทนา NPC ยังหันหาจนปิดร้าน)
2. สร้างลูกชื่อ `DialogueShots` ใส่ `DialogueShotRig` ข้างในมี Cinemachine Camera 2 ตัว **ชื่อต้องตรงตามนี้** `DialogueShot_CloseUp` (มุมใกล้หน้า) กับ `DialogueShot_Medium` (มุมครึ่งตัว) ไฟล์ blends ใช้ชื่อนี้ตั้งให้ตัดภาพ Priority ปล่อยไว้ 0
3. วางกล้องไว้ด้านหน้า NPC (แกน +z ของตัว NPC) ทั้งสองตัวอยู่ฝั่งเดียวกัน ตอนเริ่มคุย ชุดกล้องจะหันไปทางผู้เล่นแล้วค้างทิศไว้จนคุยจบ ไม่หมุนตามตัว NPC ที่กำลังหันตัว
4. NPC ที่คุยบ่อย เช่นร้านค้า เอาติ๊ก **Use In Dialogue** ออก จะใช้สายตาผู้เล่นตลอด

กฎ: สายตาผู้เล่นเป็นมุมหลักเสมอ (หันกล้องได้) มุมอื่นใช้เฉพาะตอนที่เนื้อหาขอ คือ `DialogueOption.Shot` ของตัวเลือกที่ผู้เล่นกด ตอนนี้มีแค่ "รับเควส" (`NPCQuestGiver`) ที่ขอมุมใกล้หน้า ตัวเลือกอื่นเป็นสายตาผู้เล่น ถ้าอยากเน้นจังหวะไหนเพิ่ม ให้ตั้ง `Shot` ตอนสร้างตัวเลือกนั้นในความสามารถของ NPC เมนูตัวเลือก = ค้างมุมเดิม, อยู่มุมหนึ่งอย่างน้อย 1.5 วินาที (ปรับได้ที่ `DialogueShotDirector` ในฉาก Core) ระหว่างที่เป็นมุมของ NPC ผู้เล่นหันกล้องไม่ได้

## ห้ามลืม

- **ผลถาวรห้ามอยู่ใน Signal ของ Timeline** เช่น เริ่มเควสหรือให้ของ ให้ใช้ Finish Event หรือ Player End Point แทน เพราะตอนกดข้าม Signal อาจไม่ถูกเรียก หรือถูกเรียกพร้อมกันหมด Signal ใช้ได้แค่กับของสวยงาม เช่น เสียงหรือ particle
- **ห้ามลากของจากฉาก Core ใส่ Timeline** เช่น กล้องผู้เล่นหรือตัวผู้เล่น Unity อ้างข้ามฉากไม่ได้
- **ตอนจบ นักแสดงจะค้างอยู่ตรงที่ Timeline ทิ้งไว้** ถ้าตำแหน่งนั้นควรเป็นถาวรหลังโหลด save ต้องให้ระบบของนักแสดงจำเอง Timeline ไม่ได้ลง save
- กล้องใน Stage ต้องมี Priority 0 ทุกตัว
- clip ท่าทางที่วางในแถว ค่า **Post-Extrapolation** ตั้งเป็น Hold มาเอง แปลว่าหลัง clip จบ ท่าสุดท้ายจะค้างไว้จนถึง clip ถัดไป ช่องว่างจึงไม่ได้ว่างจริง
